# ez2lazer resources

Fork of [ppy/osu-resources](https://github.com/ppy/osu-resources) for [Ez2Lazer](https://github.com/SK-la/osu). Third-party works keep their original licences; local licence files are added where assets are redistributed. Changes in this repository are by SK-la and are unrelated to the upstream ppy authors.

## Requirements

Intended as a dependency of Ez2Lazer (`ez2lazer.Game.Resources`, or the local project reference). Upstream package: [ppy/osu-resources](https://github.com/ppy/osu-resources).
